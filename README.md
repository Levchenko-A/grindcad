# GrindCAD

A small experimental CAD system written in Python.

The purpose of GrindCAD is to explore how a CAD system can be built
from first principles while learning software architecture,
computational geometry, graphics, and engineering workflows.

## Current version

v0.0.1

## Initial functionality

- Points
- Lines
- Circles
- Rectangles
- Selection
- Deletion
- DXF export

## Philosophy

Start small.

Understand the geometry.

Build the tools ourselves.

Add complexity only when it becomes necessary.

## Technology

- Python
- PySide6
- NumPy
- ezdxf
